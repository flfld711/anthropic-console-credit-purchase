## Anthropic Console 的充值逻辑：先买 credits，用完为止

按官方帮助文档的说明，Claude API、控制台里的 playground，以及 Claude Code 的用量，都从同一个额度池里扣：预付 usage credits。先用后扣，额度用完 API 会直接停用，补了才能继续调，不会产生欠费。

几个容易踩坑的计费细节，官方写得比较清楚：

- 只对成功返回的请求收费，失败的请求不扣钱；
- 例外情况：如果请求本身会成功，但你的客户端中途断开或超时，这次调用照样计费——跑长任务时别轻易中断脚本；
- 额度耗尽只是暂停调用，不影响账号本身。

绑卡本身不产生任何扣费，真正的扣款发生在你点击购买 credits 的时候。

### 买 credits 的具体步骤

1. 用有 Admin 或 Billing 权限的账号登录 Console；
2. 进入 Settings 里的 Billing 页面；
3. 点击 Buy credits，输入想购买的金额并确认；
4. 额度即时到账，同一页面能看到当前余额和消耗明细。

### 自动续充：比手动充值更省心的做法

Billing 页面里有个 Auto-reload 区域，点 Edit 可以开启自动续充。逻辑很简单：你设两个数——触发充值的最低余额，以及每次自动补多少。余额一低于阈值就自动购买，线上服务不会因为额度耗尽而半夜挂掉，也不用天天盯着余额看。

### 关于额度有效期，先记住这一条

> credits 从购买日起一年内有效，到期作废，无法延期，且所有购买不退款。

这是官方 Credit Terms 里最核心的一条限制。过期的额度会在 Billing 页面的 Invoice history 里体现，钱是要不回来的。所以充值节奏建议小额多次，或者干脆交给 Auto-reload，别一次性囤一大笔放在账上等它过期。

## 绑卡用什么卡：Visa/MasterCard 是硬门槛

Anthropic 通过 Stripe 处理付款，对卡的要求很明确：

- **Visa 或 MasterCard**，且必须支持美元国际支付；
- 国内银联卡不支持；
- 虚拟卡和实体卡都可以，满足上面两条就行。

在 Add payment method 里要填的东西不复杂：16 位卡号、有效期、CVC 安全码，再加一组账单地址（含邮编）。账单地址填一个真实的国外地址即可，网上流传的教程多以美国地址做示例。

网络环境同样有影响。Anthropic 对注册和使用地区有限制，大陆 IP 下绑卡容易被拒，实操中一般建议挂美国或香港节点再操作。

### 绑卡失败，按这个顺序排查

1. 确认卡片支持外币/国际扣款——这是最常见的失败原因；
2. 换成美国或香港 IP，用浏览器无痕窗口重试；
3. 怀疑被 Stripe 风控的话，换一个账单地址或换一张卡再试。

绑卡成功后如果要换卡，路径是 Billing 页面里点当前支付方式旁边的铅笔图标，在弹窗里填入新卡信息更新即可。

## 常见问题

### Anthropic Console 充值支持支付宝或微信吗？

不支持。官方付款方式就是信用卡（Visa/MasterCard）和面向企业的月度账单，国内用户需要先通过虚拟卡等途径拿到一张可国际扣款的卡。

### 充值的 credits 没用完可以退吗？

不可以。官方条款写明所有购买不可退款，额度自购买日起一年过期，过期作废。

### 绑卡之后会被立刻扣钱吗？

不会。绑卡只是添加支付方式，实际扣款发生在你购买 credits 或自动续充触发时。

### Console 账号和 Claude Pro 是一回事吗？

不是。Claude Pro 是面向普通用户的网页版会员，按月订阅（$20/月）；Console 是开发者平台，管的是 API key、用量监控和计费，按 token 付费，两边是独立的账号体系。

### 注册 API 需要审批吗？

目前不需要。API 已开放注册，邮箱验证通过后就能进控制台创建 key：Settings → API Keys → Create key，生成的密钥格式类似 sk-ant-api-xxxxx。

### 怎么把充值成本压低？

三个方向：能用 Haiku 的任务别用 Opus；批量处理走 Batch API 直接半价；设好 Usage Limits 和 Auto-reload，避免浪费和断供两头吃亏。
